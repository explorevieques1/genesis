# Trading Corpus Index

31 cloned third-party repos kept as reference for ideas, patterns, and
implementations. **They are not the project.**

## Where it lives

On an **external SSD**, not the internal disk — 22 GB, deliberately not duplicated:

```
/run/media/gzacc2002/Extreme SSD/Github Repos/Trading
```

Reached through the `corpus/` symlink in the repo root, which is gitignored and
machine-local. Two commands:

| Command | Does |
|---|---|
| `python3 scripts/check_corpus.py --paths` | Is the drive mounted? Does every `INDEX.md` citation still resolve? |
| `bash scripts/link_corpus.sh` | Recreate the symlink after a remount |

**When the drive is unplugged, `corpus/` dangles and every path silently fails.**
Run the checker at the start of any session that will lean on the corpus. An
agent that can't find a repo must say so, not guess at the code — see
[[Working With Claude Code]].

Canonical index: `Genesis Agent/INDEX.md` (curated) and `INDEX.auto.md` (generated by
`build_index.sh`). This note is the Genesis-facing view.

**Citations are repo-relative.** Under the `### vectorbt` heading, the entry
`vectorbt/portfolio/` means `corpus/vectorbt/vectorbt/portfolio/` — the first
segment is the package inside the repo, not the repo itself.

## The working rules — non-negotiable

1. **Read `INDEX.md` first.** It maps every repo and points at specific files.
2. **Delegate deep digging to a `trading-researcher` subagent** so exploration tokens
   stay out of the main conversation. Ask for `repo/file.py` citations and short
   snippets — never file dumps.
3. **Never load a whole repo, notebook, or README into context.** Path:
   `INDEX.md` → targeted `grep` → read one file → stop.
4. **Never modify a cloned repo.** New code lives in the Genesis project tree.
5. Refresh with `bash build_index.sh`, then fold anything useful into the curated
   `INDEX.md` by hand.

## The one rule worth repeating

Every risk and performance formula in this system already exists, correct and tested,
in `empyrical/stats.py`. Getting a Sharpe ratio subtly wrong is easy, silent, and
expensive. **Use the reference implementation.**
